[نسخه ۷.۰.۰] - تاریخ انتشار ثبت نشده

✨ اضافه شده (Added)

- 🎨 سیستم طراحی Luxury UI: اضافه شدن سیستم طراحی جدید با ظاهر لوکس، مدرن و الهام‌گرفته از میزهای بازی حرفه‌ای.
- 🪄 افکت‌های بصری جدید: اضافه شدن افکت‌های Velvet Texture، Luxury Glass، Gold Glow، Spotlight، Shimmer و Burst Particles.
- 🖼️ مجموعه آیکون‌های اختصاصی SVG: جایگزینی آیکون‌های رابط کاربری با ۲۲ آیکون SVG اختصاصی.
- 👤 سیستم آواتار پیشرفته: امکان انتخاب آواتار و آپلود تصویر شخصی برای پروفایل بازیکن.
- 👥 سیستم دوستان و چت آنلاین: اضافه شدن ارتباط کاربران، ارسال درخواست دوستی، گفت‌وگوی آنلاین و دعوت دوستان به بازی.
- 🔐 سیستم احراز هویت: اضافه شدن API ثبت‌نام، ورود و دریافت اطلاعات حساب کاربری.
- 💬 سیستم واکنش (Reactions): اضافه شدن امکان ارسال واکنش‌های ایموجی در محیط بازی.
- 🎵 موسیقی پس‌زمینه: اضافه شدن قابلیت مدیریت موسیقی پس‌زمینه و تنظیم مستقل صدای موسیقی و افکت‌ها.
- 🧪 سیستم دیباگ و تست: اضافه شدن ابزارهای بررسی وضعیت بازی و تست ماژول‌های اصلی.
- 📚 مستندات توسعه‌دهندگان: تکمیل مستندات معماری، API، ساختار فایل‌ها و نحوه ارتباط بخش‌های مختلف پروژه.

🔄 تغییر یافته (Changed)

- 🏗️ بازطراحی معماری پروژه: تفکیک منطق بازی، رابط کاربری و مدیریت اطلاعات با هدف افزایش توسعه‌پذیری و نگهداری آسان‌تر کد.
- 📦 ماژولار شدن JavaScript: سازمان‌دهی کدها در ماژول‌های مستقل با استفاده از الگوی IIFE.
- 🎨 بازطراحی کامل رابط کاربری: بهبود ظاهر صفحات، کارت‌ها، دکمه‌ها، مودال‌ها و اجزای گرافیکی.
- 🌈 به‌روزرسانی سیستم تم‌ها: پشتیبانی از پنج رنگ اصلی شامل طلایی، زمردی، اقیانوسی، سلطنتی و یاقوتی.
- 🃏 شخصی‌سازی کارت‌ها و میز بازی: توسعه گزینه‌های ظاهری برای پشت کارت‌ها و پس‌زمینه میز.
- 📱 بهینه‌سازی طراحی واکنش‌گرا: توسعه چیدمان برای اندازه‌های مختلف صفحه‌نمایش و دستگاه‌های موبایل.
- 🔊 بهبود سیستم صوتی: توسعه افکت‌های صوتی و افزودن کنترل جداگانه برای موسیقی و افکت‌ها.
- 💾 بهبود مدیریت اطلاعات: سازمان‌دهی ذخیره‌سازی پروفایل، تنظیمات، آمار، تاریخچه و دستاوردها در LocalStorage.
- 🌐 تفکیک سرورهای بک‌اند: جداسازی سرور بازی آنلاین از سرور دوستان، چت و احراز هویت.
- ⚡ بهینه‌سازی عملکرد: استفاده از انیمیشن‌های مبتنی بر Transform و Opacity، بارگذاری بهینه آیکون‌ها و کاهش پردازش‌های غیرضروری.

🐛 رفع باگ و بهبود پایداری (Fixed)

- 🧩 بهبود ساختار ماژول‌ها برای کاهش تداخل بین بخش‌های مختلف برنامه.
- 🛠️ اضافه شدن ابزارهای تشخیص خطا و بررسی وضعیت داخلی بازی.
- 🔄 بهبود مدیریت رویدادهای بازی و ارتباط بین ماژول‌های مختلف.
- 📱 بهبود سازگاری رابط کاربری با اندازه‌های مختلف نمایشگر.

- 🎁 جایزه روزانه: امکان دریافت ۵۰ سکه رایگان در هر ۲۴ ساعت.
- 📊 تب آمار (Stats): نمایش تعداد بازی‌ها، دست‌های برده، رکورد پیاپی و زمان بازی.
- 📖 راهنمای مودال: انتقال راهنمای بازی به صفحه تنظیمات و نمایش آن در قالب مودال.

- 🏗️ بهینه‌سازی چیدمان نوار بالایی و کنترل‌های شب، روز و صدا.

- 🪙 توسعه اقتصاد بازی: گسترش امکانات فروشگاه، آیتم‌های ویژه و شخصی‌سازی بیشتر.
